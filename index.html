اختيار من متعدد تفاعلي
السؤال 1 (مقارنة مقادير لوغاريتمية): قارن بين المقدارين $A = \ln^3\left(\frac{1}{e^2}\right)$ و $B = \ln\left[\left(\frac{1}{e^2}\right)^3\right]$:
أ) $A = B$
ب) $A > B$
ج) $A < B$ (أي $B > A$)
د) غير معرّف
• المقدار الأول: $\ln\left(\frac{1}{e^2}\right) = \ln(e^{-2}) = -2$. وبالتالي: $$A = \left[\ln\left(\frac{1}{e^2}\right)\right]^3 = (-2)^3 = -8$$ • المقدار الثاني بتطبيق خواص قوى اللوغاريتم: $$B = \ln\left[\left(\frac{1}{e^2}\right)^3\right] = 3 \ln\left(\frac{1}{e^2}\right) = 3(-2) = -6$$ بما أن $-6 > -8$، فإن $B > A$ أي $A < B$.
السؤال 2: مجموعة تعريف التابع $f(x) = \ln^2(x-3)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $[3, +\infty[$
د) $\mathbb{R}$
التربيع على التابع كاملاً: $\ln^2(x-3) = [\ln(x-3)]^2$. يشترط فقط أن يكون ما داخل اللوغاريتم موجباً تماماً: $x - 3 > 0 \implies x > 3 \implies D_f = ]3, +\infty[$.
السؤال 3: مجموعة تعريف التابع $f(x) = \ln\left((x-3)^2\right)$ هي:
أ) $]3, +\infty[$
ب) $\mathbb{R} \setminus \{3\}$
ج) $]0, +\infty[$
د) $]-\infty, 3[$
التربيع داخل اللوغاريتم: يشترط $(x-3)^2 > 0$. المربع موجب دوماً لجميع الأعداد الحقيقية عدا القيمة التي تعدمه: $x - 3 \ne 0 \iff x \ne 3$. إذن: $D_f = \mathbb{R} \setminus \{3\}$.
السؤال 4: مجموعة تعريف التابع $f(x) = \ln|x-5|$ هي:
أ) $]5, +\infty[$
ب) $\mathbb{R} \setminus \{5\}$
ج) $]-\infty, 5[$
د) $[5, +\infty[$
القيمة المطلقة موجبة دوماً ما عدا عندما ينعدم ما بداخلها: $|x-5| > 0 \iff x - 5 \ne 0 \iff x \ne 5 \implies D_f = \mathbb{R} \setminus \{5\}$.
السؤال 5: مجموعة تعريف التابع $f(x) = \ln(x^2 + 3)$ هي:
أ) $\mathbb{R}$ كاملاً
ب) $]0, +\infty[$
ج) $\mathbb{R} \setminus \{-\sqrt{3}, \sqrt{3}\}$
د) $]\sqrt{3}, +\infty[$
المقدار $x^2 + 3 \ge 3 > 0$ موجب تماماً أياً كانت $x \in \mathbb{R}$، لذلك التابع معرف على كامل مجموعة الأعداد الحقيقية $\mathbb{R}$.
السؤال 6: مجموعة تعريف التابع $f(x) = \ln\left(\frac{x+2}{x}\right)$ هي:
أ) $]0, +\infty[$
ب) $]-2, 0[$
ج) $]-\infty, -2[ \cup ]0, +\infty[$
د) $\mathbb{R} \setminus \{-2, 0\}$
يشترط أن يكون ما بداخل اللوغاريتم موجباً تماماً: $\frac{x+2}{x} > 0$.
بدراسة إشارة الكسر: ينعدم البسط عند $x = -2$ وينعدم المقام عند $x = 0$. الكسر موجب خارج مجال الجذرين، ومنه: $$D_f = ]-\infty, -2[ \cup ]0, +\infty[$$
السؤال 7: قيمة النهاية $\lim_{x \to 0^+} \sqrt{x}\ln(x)$ تساوي:
أ) $-\infty$
ب) $0$
ج) $1$
د) $+\infty$
نضع المتحول المساعد $t = \sqrt{x} \iff x = t^2$. عندما $x \to 0^+$ فإن $t \to 0^+$:
$$\lim_{x \to 0^+} \sqrt{x}\ln x = \lim_{t \to 0^+} t \ln(t^2) = 2 \lim_{t \to 0^+} (t \ln t) = 2(0) = 0$$
السؤال 8: إذا كان $f(x) = \frac{\ln x}{x^2}$، فإن القيمة الكبرى محلياً للتابع هي:
أ) $1$
ب) $\frac{1}{2e}$
ج) $\frac{1}{e}$
د) $e$
المشتق: $f'(x) = \frac{\frac{1}{x} \cdot x^2 - (\ln x)(2x)}{x^4} = \frac{1 - 2\ln x}{x^3}$.
ينعدم المشتق عندما $1 - 2\ln x = 0 \iff \ln x = \frac{1}{2} \iff x = e^{1/2} = \sqrt{e}$.
القيمة الكبرى هي صورة هذه النقطة: $$f(\sqrt{e}) = \frac{\ln(e^{1/2})}{(\sqrt{e})^2} = \frac{1/2}{e} = \frac{1}{2e}$$

احسب النهايات الآتية مع إزالة عدم التعيين والتعليل المفصل:
1) $\lim_{x \to +\infty} \left[\ln(2x+1) - \ln(x)\right]$
2) $\lim_{x \to +\infty} \left[2x \ln\left(1 + \frac{1}{2x}\right)\right]$
3) $\lim_{x \to +\infty} \frac{\ln(x)}{x^2}$ (بالتفكيك وفق $\lim_{x \to +\infty}\frac{\ln x}{x} = 0$)
4) $\lim_{x \to +\infty} \frac{2 + \ln(x)}{3 + 4\ln(x)}$
5) $\lim_{x \to 0^+} \left[\sqrt{x}\ln(x)\right]$
6) $\lim_{x \to +\infty} \left[\ln(x) - x\right]$
7) $\lim_{x \to 0} \frac{\ln(1+3x)}{\sin(2x)}$
1) $\lim_{x \to +\infty} [\ln(2x+1) - \ln x]$:
حالة $[\infty - \infty]$. نحول الفرق إلى كسر: $$\lim_{x \to +\infty} \ln\left(\frac{2x+1}{x}\right) = \lim_{x \to +\infty} \ln\left(2 + \frac{1}{x}\right) = \ln(2 + 0) = \ln 2$$
2) $\lim_{x \to +\infty} \left[2x \ln\left(1 + \frac{1}{2x}\right)\right]$:
حالة $[\infty \times 0]$. نضع $t = \frac{1}{2x} \implies 2x = \frac{1}{t}$. عندما $x \to +\infty$ فإن $t \to 0^+$: $$\lim_{t \to 0^+} \frac{\ln(1+t)}{t} = 1$$
3) $\lim_{x \to +\infty} \frac{\ln x}{x^2}$ بالتفكيك السلمي المعتمد:
نفكك الكسر: $$\lim_{x \to +\infty} \frac{\ln x}{x^2} = \lim_{x \to +\infty} \left(\frac{1}{x} \cdot \frac{\ln x}{x}\right) = 0 \cdot 0 = 0$$
4) $\lim_{x \to +\infty} \frac{2 + \ln x}{3 + 4\ln x}$:
نخرج $\ln x$ عاملاً مشتركاً من البسط والمقام: $$\lim_{x \to +\infty} \frac{\ln x \left(\frac{2}{\ln x} + 1\right)}{\ln x \left(\frac{3}{\ln x} + 4\right)} = \frac{0 + 1}{0 + 4} = \frac{1}{4}$$
5) $\lim_{x \to 0^+} [\sqrt{x}\ln x]$:
نضع $t = \sqrt{x} \iff x = t^2$. عندما $x \to 0^+$ فإن $t \to 0^+$: $$\lim_{x \to 0^+} \sqrt{x}\ln x = \lim_{t \to 0^+} t \ln(t^2) = 2 \lim_{t \to 0^+} (t \ln t) = 2(0) = 0$$
6) $\lim_{x \to +\infty} [\ln(x) - x]$:
نخرج $x$ عاملاً مشتركاً: $$\lim_{x \to +\infty} x \left(\frac{\ln x}{x} - 1\right) = (+\infty)(0 - 1) = -\infty$$
7) $\lim_{x \to 0} \frac{\ln(1+3x)}{\sin(2x)}$:
نقسم البسط والمقام على $x$: $$\lim_{x \to 0} \frac{3 \cdot \frac{\ln(1+3x)}{3x}}{2 \cdot \frac{\sin(2x)}{2x}} = \frac{3(1)}{2(1)} = \frac{3}{2}$$

4) اكتب معادلة المماس عند $x = 1$ واحسب بالتقريب التآلفي قيمة $f(1.1)$.
• الاستمرار: $\lim_{x \to 0^+} f(x) = \frac{0}{0 - (-\infty)} = \frac{0}{+\infty} = 0 = f(0)$، فالتابع مستمر عند الصفر من اليمين.
• الاشتقاق: $$\lim_{x \to 0^+} \frac{f(x) - f(0)}{x - 0} = \lim_{x \to 0^+} \frac{1}{x - \ln x} = \frac{1}{+\infty} = 0$$ التابع اشتقاقي عند الصفر من اليمين و $f'_d(0) = 0$. التفسير الهندسي: يقبل المنحني عند المبدأ مماس أفقي ممتداً باتجاه اليمين.
• المقارب الأفقي: $\lim_{x \to +\infty} \frac{1}{1 - \frac{\ln x}{x}} = \frac{1}{1-0} = 1 \implies y = 1$ مقارب أفقي بجوار $+\infty$.

• التقريب التآلفي: $f(1.1) \approx f(1) + 0.1 \cdot f'(1) = 1 + 0.1(1) = 1.1$.
تمرين 2: دراسة استمرار واشتقاق التابع $f(x) = x^2(1 - \ln x)$ والمماس الأفقي والتقريب

• الاستمرار: $\lim_{x \to 0^+} [x^2 - x(x\ln x)] = 0 - 0 = 0 = f(0)$، فالتابع مستمر عند الصفر من اليمين.
• الاشتقاق: $\lim_{x \to 0^+} \frac{x^2(1 - \ln x)}{x} = \lim_{x \to 0^+} [x - x\ln x] = 0 = f'_d(0)$. يقبل المنحني عند المبدأ مماس أفقي.
• المماس عند $x = 1$: $f(1) = 1$، $f'(x) = x(1 - 2\ln x) \implies f'(1) = 1 \implies (T): y = x$.
• التقريب التآلفي: $f(1.1) \approx 1 + 0.1(1) = 1.1$.
